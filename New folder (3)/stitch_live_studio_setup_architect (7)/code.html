menu_book Recording Guide

  • 1
    Connect Hardware
    Ensure your microphone or instrument is properly connected to input 1 of your audio interface.
  • 2
    Set Preamp Gain
    Gradually increase the input gain while speaking or playing. Aim for levels around -18dB to -12dB to leave headroom.
  • 3
    Arm the Track
    In your chosen DAW, select the correct input channel and arm the track for recording. Check software meters.
  • 4
    Start Recording Test
    Use the monitor below to ensure signal flows properly before capturing the final take.
