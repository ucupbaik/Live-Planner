Panduan Realisasi

Blueprint Arsitektur Live Streaming

Alur sinyal dasar sebuah siaran langsung:

[Kamera] --HDMI/SDI--> [Video Switcher] --SDI--> [Capture Card] --USB--> [PC OBS/vMix]
   |                                  |                                      |
[Microphone] --XLR/Audio--> [Audio Mixer] --Audio--> [Switcher/Encoder]   [Encoder] --RTMP--> [Platform Live]
  • Kamera menangkap video; output HDMI/SDI masuk ke switcher.
  • Video Switcher memilih sumber gambar & menggabungkan layer.
  • Capture Card mengubah sinyal video menjadi data ke PC.
  • Audio Mixer menyeimbangkan mic & musik sebelum ke encoder.
  • Encoder / OBS mengompres & mengirim stream via RTMP ke platform.
  • Monitor & Tally membantu kru melihat hasil & status on-air.

Cara Instalasi & Penggunaan

  1. Pilih alat: Buka katalog kiri, cari alat, centang lalu klik untuk menaruh di kanvas.
  2. Susun posisi: Tarik judul alat (handle) untuk memindahkan; scroll untuk zoom; drag area kosong untuk pan.
  3. Hubungkan kabel: Klik port (Output) lalu port Input alat tujuan. Warna = jenis kabel.
  4. Rangkai otomatis: Centang beberapa alat lalu klik Rangkai Otomatis untuk menyambung port yang cocok otomatis.
  5. Catatan & Setting: Klik untuk catatan, untuk setting software (resolusi, bitrate, server).
  6. Simpan: Klik Save (perlu login admin) atau export gambar .
  7. Cetak ringkasan: Klik Ringkasan Cetak untuk PDF daftar alat & kabel.
  8. Generate dari gambar: Klik Generate dari Gambar, unggah foto produk, isi nama & kategori, lalu Buat Alat.

Troubleshooting

MasalahSolusi
Kabel ditolak / tidak nyambungPastikan tipe port cocok (HDMI→HDMI, SDI→SDI, Audio→Audio) dan arah Output→Input.
Gambar alat tidak munculGambar fallback Font Awesome akan tampil. Pastikan file di folder images_real/ terunggah ke repo.
Data tidak tersimpanLogin sebagai admin di panel kiri. Simpanan disimpan ke Turso (cloud).
API /api/equipment gagalCek env TURSO_URL & TURSO_TOKEN di Vercel. Fallback ke equipment-data.js lokal otomatis.
Zoom/pan tidak responsifKlik area kanvas kosong lalu drag untuk pan; scroll mouse untuk zoom.
Deploy gagal di VercelPastikan vercel.json rewrite /api benar & @libsql/client ter-install (npm install).
