Blueprint Arsitektur Live Streaming

[Kamera] --HDMI/SDI--> [Video Switcher] --SDI--> [Capture Card] --USB--> [PC OBS/vMix]
   |                                  |                                      |
[Microphone] --XLR/Audio--> [Audio Mixer] --Audio--> [Switcher/Encoder]   [Encoder] --RTMP--> [Platform Live]
  • Kamera menangkap video; output HDMI/SDI ke switcher.
  • Video Switcher memilih & menggabungkan sumber gambar.
  • Capture Card mengubah sinyal video jadi data ke PC.
  • Audio Mixer menyeimbangkan mic & musik.
  • Encoder / OBS mengompres & kirim stream via RTMP.
  1. Pilih modul di beranda, lalu pilih alat dari katalog kiri.
  2. Susun: tarik judul alat, scroll untuk zoom, drag area kosong untuk pan.
  3. Hubungkan: klik port output lalu port input alat tujuan.
  4. Rangkai Otomatis: pilih alat lalu klik tombol tersebut.
  5. Simpan / Template: Simpan ke akun Anda atau publikasikan sebagai template.
  6. Bagikan: salin tautan untuk dilihat orang lain tanpa login.

Kelola Daftar Alat (Equipment)

Keterangan Kolom CSV

  • no — Nomor urut (angka, opsional)
  • name — Nama alat (wajib)
  • brand — Merek alat
  • category — Kategori (mis. Kamera, Switcher, Audio, PC, Kabel)
  • img — URL gambar alat
  • emoji — Ikon emoji (mis. 🎥 🔊 💻)
  • has_settings — 1 jika punya pengaturan, 0 jika tidak
  • inputs — Daftar input, format: Nama|Jenis; Nama2|Jenis2 (mis. HDMI|Video; XLR|Audio)
  • outputs — Daftar output, format sama seperti inputs
  • func — Keterangan / spesifikasi alat
  • ports_raw — Catatan port mentah (teks bebas)
